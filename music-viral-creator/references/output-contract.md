# Output Contract

Use this template for full song-planning tasks. Keep it compact, but do not omit required sections.

## 1. 市场趋势抽象

- 样本说明：平台 / 时间 / 样本量 / 可信度
- 情绪分布：例如 `70%伤感 / 20%甜 / 10%燃`
- BPM规律：例如 `80-100最集中，适合慢卡点和情绪铺垫`
- Hook规律：例如 `前8秒进入人声或旋律Hook`
- 结构规律：例如 `短前奏 -> 早Hook -> 副歌爆点 -> 留白`
- 歌词主题：分手 / 孤独 / 成长 / 暗恋 / 和解等
- 可复用结论：3-5条创作规则

Default rule:

```text

```


Metric guide:

- 完播率 > 35%：结构有效；低于 25%：前奏/副歌进入太慢。
- 点赞率 > 5%：情绪有效；低于 2%：情绪或演唱不打人。
- 收藏率 > 2%：歌词/场景有复用价值；低于 1%：文案价值弱。
- 评论率 > 0.5%：共鸣有效；低于 0.2%：金句不够像用户心里话。
- 转发率 > 0.8%：二创/传播性强；低于 0.3%：场景适配弱。
